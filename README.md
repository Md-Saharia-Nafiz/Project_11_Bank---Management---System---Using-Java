



## Bank - Management - System - Using Java

Create Java Bank Management System Add account creation, deposit, withdrawal, balance check and money transfer Implement file handling to permanently store account data.


## 📄Description:


A basic Java-based Bank Management System designed using Object-Oriented Programming (OOP) concepts. The system allows users to create and manage multiple bank accounts efficiently. It supports essential banking operations such as deposit, withdrawal, balance checking, and money transfer. Users can view individual account details as well as all available accounts. File Handling is implemented to permanently store and retrieve account information without using a database. The project demonstrates Java concepts including classes, objects, ArrayList, methods, encapsulation, and file handling. This project is developed as a simple, user-friendly, and beginner-level console-based banking application. 


## 💡 Key Concepts Used:

* Object-Oriented Programming (OOP) — Classes, Objects, Encapsulation
* Class & Object — BankManagementSystem and Account
* ArrayList — Managing and storing multiple bank accounts
* File Handling — Saving and loading account data using accounts.txt
* Basic Banking Operations — Deposit, Withdraw, Balance Check & Money Transfer
* Methods & Constructors — Organizing program functionality
* Encapsulation — Using private data members with getter methods
* Conditional Statements — Validating transactions and user input
* Loops — Running the banking menu continuously
* Switch-Case — Handling different menu options
* Exception Handling — Managing file-related errors with try-catch
* Input Handling — Taking user input using Scanner
* CRUD Operations — Creating, viewing, updating, and managing accounts

## ✨ Features:

* 🏦 **Create New Bank Account** — Create a new account with account number, account holder name, and initial deposit.
* 💰 **Deposit Money** — Deposit money into an existing bank account and update the balance automatically.
* 💸 **Withdraw Money** — Withdraw money with balance validation and insufficient-balance checking.
* 🔍 **Check Balance** — Check the current balance of any registered account.
* 👤 **Account Information** — View complete account details, including account number, holder name, and balance.
* 🔄 **Money Transfer** — Transfer money securely between two registered accounts.
* 📋 **Display All Accounts** — View all accounts currently stored in the system.
* 💾 **File-Based Data Storage** — Account information is saved in a text file, so data remains available even after closing the program.
* 🔁 **Automatic Data Loading** — Previously saved account data is automatically loaded when the program starts.
* 🖥️ **Console-Based Interface** — Simple and user-friendly menu-driven interface using Java.
* ☕ **Basic Java & OOP** — Developed using Java classes, objects, methods, ArrayList, and file handling without any database.

## 🔔 Purpose:

The purpose of this **Bank Management System** is to develop a simple, user-friendly banking application using **Basic Java and Object-Oriented Programming (OOP)** concepts.

This project allows users to : 

* 🏦 Create and manage bank accounts
* 💰 Deposit money into an account
* 💸 Withdraw money from an account
* 💳 Check account balance
* 👤 View account information
* 🔄 Transfer money between accounts
* 📋 Display all available bank accounts
* 💾 Save and load account data using **File Handling**
* 🔐 Maintain account information even after closing and reopening the program

This project is developed **without a database** and demonstrates the practical use of **Java Classes, Objects, Encapsulation, ArrayList, File Handling, Methods, Conditional Statements, Loops, and Exception Handling**.

## ▶️ How to Run:

1. Create New Account – Create a new bank account with account number, holder name, and initial deposit.

2. Deposit Money – Deposit money into an existing bank account and update the balance.

3. Withdraw Money – Withdraw money while checking for sufficient balance.

4. Check Balance – Check the current balance of any existing account.

5. Account Information – View complete account details, including account number, holder name, and balance.

6. Transfer Money – Transfer money securely from one account to another.

7. Display All Accounts – View all accounts currently stored in the system.

8. File Handling & Data Persistence – Automatically save account information in accounts.txt and load the data again when the program is restarted.
